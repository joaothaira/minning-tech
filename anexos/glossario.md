# Anexo — Glossário

| Termo | Definição |
|---|---|
| **ANM** | Agência Nacional de Mineração: reguladora federal dos títulos minerários e da CFEM |
| **APC** | *Advanced Process Control*: controle avançado de processo (modelos preditivos que ajustam a planta em tempo real) |
| **Argila iônica (IAC)** | *Ion-Adsorption Clay*: depósito em que os íons de ETR estão adsorvidos em argilas, extraíveis por troca com uma solução salina |
| **ASX / TSX** | Bolsas de valores da Austrália e de Toronto, onde estão listadas a maioria das juniores |
| **Bastnasita** | Mineral fluorocarbonato de ETR leves: o principal minério de Mountain Pass e de Bayan Obo |
| **Capex / Opex** | Investimento de capital / custo operacional |
| **Carbonatito** | Rocha ígnea rica em carbonatos, hospedeira de grandes depósitos de ETR e de nióbio |
| **CETEM** | Centro de Tecnologia Mineral (MCTI, Rio de Janeiro) |
| **CFEM** | Compensação Financeira pela Exploração Mineral: o royalty mineral brasileiro |
| **CIMCE** | Conselho Nacional para Industrialização de Minerais Críticos e Estratégicos (Lei 15.506/2026) |
| **CIT SENAI ITR** | Centro de Inovação e Tecnologia SENAI, Instituto de Terras Raras (Lagoa Santa, MG) |
| **CNEN** | Comissão Nacional de Energia Nuclear: regula material radioativo (U, Th) |
| **COPAM / SEMAD / FEAM** | Conselho, secretaria e fundação ambientais de Minas Gerais (licenciamento) |
| **CRMA** | *Critical Raw Materials Act*: regulamento europeu de matérias-primas críticas |
| **Cut-off (teor de corte)** | Teor mínimo usado para considerar um material como recurso ou minério |
| **Cesta (basket)** | Valor médio por kg da mistura de óxidos de um depósito |
| **DFARS** | Regras de aquisição de defesa dos EUA (restrições a insumos chineses) |
| **DFC** | *U.S. International Development Finance Corporation*: agência americana de financiamento externo |
| **DFS / FS / PFS** | Estudo de viabilidade definitivo / de viabilidade / de pré-viabilidade |
| **Dessorção** | Liberação de íons adsorvidos por troca com outro cátion (por exemplo, Mg²⁺ ou NH₄⁺) |
| **DPP** | *Digital Product Passport*: passaporte digital de produto (UE) |
| **Dry stacking** | Empilhamento a seco de rejeito filtrado, alternativa às barragens |
| **EIA/RIMA** | Estudo de Impacto Ambiental / Relatório de Impacto ao Meio Ambiente |
| **EPCM** | *Engineering, Procurement and Construction Management*: engenharia que projeta e gerencia a construção |
| **ETR / REE** | Elementos de Terras Raras / *Rare Earth Elements* |
| **FGAM** | Fundo Garantidor da Atividade Mineral (Lei 15.506/2026) |
| **FID** | *Final Investment Decision*: decisão final de investimento |
| **GBD** | *Grain Boundary Diffusion*: difusão de Dy/Tb nos contornos de grão do ímã |
| **Gêmeo digital** | Modelo virtual sincronizado com dados reais de uma planta, para simular e otimizar |
| **HREE / LREE** | Terras raras pesadas / leves |
| **ICP-MS / ICP-OES** | Técnicas de espectrometria para análise química de traços (essenciais para ETR) |
| **INB** | Indústrias Nucleares do Brasil: estatal que detém o monopólio de minerais nucleares |
| **IRMA** | *Initiative for Responsible Mining Assurance*: padrão de auditoria de mineração responsável |
| **ISR** | *In-Situ Recovery*: recuperação in situ (injeção de solução no solo, sem escavação) |
| **JORC / NI 43-101** | Códigos australiano e canadense de divulgação de recursos e reservas |
| **Junior** | Mineradora pequena, em geral sem receita, focada em exploração e desenvolvimento |
| **LCA** | *Life Cycle Assessment*: análise de ciclo de vida (pegada ambiental) |
| **LIMS** | *Laboratory Information Management System*: software de gestão de laboratório |
| **LP / LI / LO** | Licença Prévia / de Instalação / de Operação |
| **MagBras** | Projeto nacional da cadeia de ímãs de terras raras (~R$ 73 mi, CIT SENAI) |
| **Mixer-settler** | Misturador-decantador: unidade de um estágio de extração por solvente |
| **Monazita** | Fosfato de ETR leves com tório: mineral das areias de praia e dos carbonatitos |
| **MOFCOM** | Ministério do Comércio da China (emite os controles de exportação) |
| **MREC** | *Mixed Rare Earth Carbonate*: carbonato misto de terras raras (produto intermediário) |
| **MREO** | *Magnet Rare Earth Oxides*: óxidos de Nd + Pr + Dy + Tb |
| **NdFeB** | Ímã de neodímio-ferro-boro |
| **NdPr** | Óxido misto de neodímio e praseodímio: o principal produto de referência de preço |
| **NORM** | *Naturally Occurring Radioactive Material*: material radioativo de ocorrência natural |
| **Offtake** | Contrato de compra antecipada da produção |
| **Pagabilidade** | Percentual do valor contido que o comprador paga por um intermediário (por exemplo, o MREC) |
| **PoC** | *Proof of Concept*: prova de conceito (piloto comercial) |
| **ppm** | Partes por milhão (1% = 10.000 ppm) |
| **Recurso / Reserva** | Concentração com perspectiva de extração / parte economicamente lavrável, demonstrada por estudo |
| **Saprolito** | Rocha intemperizada no local que mantém a estrutura original. Hospeda argilas iônicas |
| **Scheme of arrangement** | Mecanismo societário australiano de aquisição aprovado por acionistas e pela justiça |
| **Separação** | Etapa química que transforma o concentrado misto em óxidos individuais |
| **SPV** | *Special Purpose Vehicle*: veículo de propósito específico |
| **SX** | *Solvent Extraction*: extração por solvente, a tecnologia dominante de separação de ETR |
| **TREO** | *Total Rare Earth Oxides*: teor total de terras raras expresso em óxidos |
| **Xenotima** | Fosfato de ítrio e ETR pesados |
